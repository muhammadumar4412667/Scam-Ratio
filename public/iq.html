How it works

Learn. Practice. Repeat.

Every challenge rewards recognition of concrete scam signals: urgency, suspicious links, impersonation, payment pressure and requests for secrets.

ScamRatio IQ is an educational experience. Scenarios are fictionalized examples designed to teach common warning signs. A game result is not a security verdict and should not be used as proof that a real message, person, website or transaction is safe.
